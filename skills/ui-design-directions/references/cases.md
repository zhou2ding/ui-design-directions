# 产品与界面案例

按要解决的问题挑选。链接指向作品或具体控件，旁边写的是可迁移的做法。产品页会改版，再次引用时打开当前版本核对。

## 官网怎样讲产品

| 作品 | 值得停下来看的一处 | 可尝试的做法 |
| --- | --- | --- |
| [Apple · MacBook Air](https://www.apple.com.cn/macbook-air/) | 用机身的侧面呈现轻薄，产品轮廓本身承担说明 | 找到能被看见的产品特点，让主图回答一个问题 |
| [Apple · Pages 文稿](https://www.apple.com.cn/pages/) | 讲编辑能力时展示具体文稿，讲模板时让选择器成为画面重点 | 用全景建立方向感，用特写讲操作。缩到手机宽度，再检查正文与界面图的可读性 |
| [HUMAN.md](https://www.human-md.ai/) | 蓝墙、绿叶、粉花盆和橙色台灯各自有明确边界 | 让亮色落在有含义的对象上，如图中某组信号或被选中的材料。它的宣言式大字未必适合工具产品 |
| [Stripe Press · The Art of Doing Science and Engineering](https://stripe.press/book/the-art-of-doing-science-and-engineering) | 书封、书脊、标题和书目信息共同介绍一本书 | 报告、出版或资料产品可以围绕一件可读的真实成果排版 |
| [CHD Art Maker · Projets](https://www.chdartmaker.com/en/projets) | 大标题、横线和作品目录组成清楚的浏览顺序 | 案例很多时，用目录和尺度变化组织内容，给案例大图留足宽度 |
| [Enode · Landdding 收录页](https://landdding.com/l/enode-com-85bb72d3) | 对象和对应读数放在同一视野 | 将状态、单位或参数靠近它所描述的对象 |
| [Runmo · ECG interaction](https://60fps.design/shots/runmo-lab-pulse-heart-ecg-interaction) | 动态曲线与读数相伴，变化来自同一过程 | 同一输入同时更新图表与数字，给动效一个能够观察的结果 |

一次实测中，Pages 模板段落的标题和说明在 1440 px 宽视口下分别为 48、19 CSS px。切到 390 px 时变成 28、17 CSS px。标题缩小了 20 px，说明文字只缩小 2 px。借鉴之处是两级文字采用不同的缩放幅度。页面和字体会更新，使用时重新测量。

## 客户端怎样打磨控件

| 参考 | 对照任务 |
| --- | --- |
| [Apple · macOS 预览使用手册](https://support.apple.com/zh-cn/guide/preview/welcome/mac) | 观察原生窗口里的内容、工具栏和导航怎样分层。手册图片适合看层级，具体尺寸需在实际窗口测量 |
| [Apple HIG · Color](https://developer.apple.com/design/human-interface-guidelines/color) | 给导航选中、主要动作、错误和图表分别安排颜色，检查深浅背景上的辨识度 |
| [GitHub Primer · Button](https://primer.style/product/components/button/) 和 [Action menu](https://primer.style/product/components/action-menu/) | 比较同一套按钮的主次，再观察按钮怎样打开菜单、选项怎样获得焦点 |
| [Adobe React Spectrum · ActionButton](https://react-spectrum.adobe.com/v3/ActionButton.html) 和 [ActionGroup](https://react-spectrum.adobe.com/v3/ActionGroup.html) | 对照独立按钮与成组按钮。重点看相邻边缘、间距、密度与选中态 |
| [Excalidraw](https://excalidraw.com/) | 打开画布，切换选中工具，再展开菜单。观察浮动工具栏的边缘以及内容与阴影的关系 |

## 八个发现作品的入口

| 入口 | 用法 |
| --- | --- |
| [Godly](https://godly.website/) | 从网页作品找视觉构图。初次调研时它跳转至 Recent，遇到同样情况只记录最终找到的作品 |
| [Land-book](https://land-book.com/) | 按页面类型找导航、下载或定价等实际段落。本次直接请求返回 HTTP 403，首批案例未从这里选取作品 |
| [60fps](https://60fps.design/) | 按交互找短演示，如选择器和状态切换。记下起始状态、用户动作和结束状态 |
| [MotionSites Studio](https://studio.motionsites.ai/) | 页面制作工具。适合验证构图或交互想法，使用前查看当前访问条件 |
| [Landdding](https://landdding.com/) | 从行业或产品分类找到具体案例，结合原作看完整滚动路径 |
| [Recent](https://recent.design/) | 从索引追到项目原站，例如上面的 Stripe Press 书页 |
| [Font In Logo](https://www.fontinlogo.com/) | 查询品牌标识的字体线索。正文的中文覆盖、可读性和字体授权仍需单独检查 |
| [MotionSites](https://motionsites.ai/3d-websites) | 从 3D 作品找物体、光照与镜头关系，同时查看静止画面能否讲清产品 |

缩小到实际手机宽度，看文字和按钮是否还能使用。网页正文、索引缩略图和成品交互能支持的判断各不相同，记录时注明看到了哪一种。
